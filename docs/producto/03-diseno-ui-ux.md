# Diseño de interacción

Una página presenta el dilema, un grupo de escenarios, los controles y la comparación de políticas. La confirmación, la espera, el rechazo y el registro irrecuperable tienen rótulos distintos. La explicación de cada diseño acompaña las métricas. La línea de tiempo separa la demanda de la pérdida posterior.

En pantallas angostas la comparación se apila sin perder el orden de lectura. Los controles tienen etiquetas, foco visible y operación por teclado. El contenido explica si el motor está cargando y permite corregir una entrada inválida sin confundir el resultado anterior con el vigente.

Los ejemplos usan cifras ficticias. Un enlace visible lleva al repositorio. Ver [flujos](04-appflow.md) y [requisitos](01-prd.md).
